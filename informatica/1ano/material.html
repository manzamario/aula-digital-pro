🔹 1er Cuatrimestre

Algoritmos y Programación

¿Qué es un algoritmo? Es una secuencia ordenada de pasos que permite resolver un problema. Ejemplo: una receta de cocina, los pasos para atarse los cordones.

Estructuras básicas:

  • Secuencial: instrucciones una tras otra.
  • Alternativa (condicional): si ocurre algo, hacer X; si no, hacer Y.
  • Repetitiva: repetir una acción varias veces.

Operadores lógicos: Y (AND), O (OR), NOT (NO).

Operadores de comparación: >, <, =, ≥, ≤, ≠.

Software Libre

Software libre: es aquel que respeta la libertad del usuario. Sus 4 libertades:

  1. Ejecutar el programa con cualquier propósito.
  2. Estudiar cómo funciona y modificarlo.
  3. Redistribuir copias.
  4. Mejorar el programa y publicar mejoras.

Licencias: GPL, AGPL, BSD, Apache, Creative Commons.

Software propietario: Freeware (gratis pero cerrado), Shareware (prueba limitada).

🔹 2do Cuatrimestre

Arquitectura de Computadoras

Hardware: parte física. Software: parte lógica.

Arquitectura de Von Neumann: CPU + Memoria + Entrada/Salida.

Memoria: RAM (volátil), ROM (solo lectura), Cache (rápida), EPROM.

Sistema binario: 0 y 1. Bit, byte (8 bits), KB, MB, GB, TB.

Almacenamiento: pendrive, disco, DVD, nube.

Seguridad Informática

Seguridad informática: protege integridad, confidencialidad y disponibilidad.

Riesgos: ciberbullying, grooming, sexting, phishing, malware.

Contraseñas seguras: largas, con mayúsculas, números y símbolos.

Buenas prácticas: no compartir datos personales, verificar fuentes, usar antivirus.

🔹 Archivos y organización

Un archivo guarda información y una carpeta permite organizar varios archivos. El nombre, la extensión y la ubicación ayudan a identificar cada elemento.

  • Texto: .txt, .odt, .docx.
  • Imagen: .jpg, .png.
  • Audio y video: .mp3, .mp4.
  • Comprimidos: .zip.

Buenas prácticas: usar nombres claros, separar por carpetas, hacer copias de seguridad y eliminar duplicados.

🔹 Búsqueda y fuentes confiables

Antes de compartir una información hay que revisar quién la publica, la fecha, las fuentes citadas y si otros sitios confiables confirman el dato.

Una búsqueda precisa combina palabras clave y evita copiar contenido sin comprenderlo ni reconocer su autoría.
