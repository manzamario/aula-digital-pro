Material de estudio y dictado

🔹 Programación

Programar es expresar una solución mediante instrucciones. Un programa recibe datos, los procesa y produce resultados.

  • Funciones: organizan instrucciones reutilizables.
  • Listas: almacenan varios valores.
  • Eventos: responden a acciones del usuario.
  • Depuración: localiza y corrige errores.

🔹 Diseño web

HTML estructura el contenido, CSS define su presentación y JavaScript agrega comportamiento. Una página accesible usa títulos claros, etiquetas semánticas, contraste y textos alternativos.

🔹 Datos y seguridad

Una base de datos organiza información en tablas relacionadas. Para cuidarla hay que validar datos, limitar permisos, hacer copias de seguridad y evitar compartir información personal sin autorización.
