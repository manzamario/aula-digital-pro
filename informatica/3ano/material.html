Informática - 3° Año

Material de estudio y dictado

🔹 Programación

Programar es expresar una solución mediante instrucciones. Un programa recibe datos, los procesa y produce resultados.

  • Funciones: organizan instrucciones reutilizables.
  • Listas: almacenan varios valores.
  • Eventos: responden a acciones del usuario.
  • Depuración: localiza y corrige errores.

🔹 Diseño web

HTML estructura el contenido, CSS define su presentación y JavaScript agrega comportamiento. Una página accesible usa títulos claros, etiquetas semánticas, contraste y textos alternativos.

🔹 Datos y seguridad

Una base de datos organiza información en tablas relacionadas. Para cuidarla hay que validar datos, limitar permisos, hacer copias de seguridad y evitar compartir información personal sin autorización.

🔹 Bases de datos y consultas

Una tabla contiene registros y campos. La clave primaria identifica cada registro y una clave foránea relaciona tablas.

  • SELECT: consulta información.
  • WHERE: filtra resultados.
  • ORDER BY: ordena datos.
  • INSERT: agrega registros.

Una consulta debe pedir solo los datos necesarios y respetar los permisos de acceso.

🔹 Desarrollo responsable

Un proyecto tecnológico comienza con una necesidad, define usuarios y objetivos, diseña una solución, la implementa, prueba y mejora.

La accesibilidad, la privacidad, la seguridad y el impacto ambiental deben considerarse desde el diseño, no al final.

🔹 JavaScript y el navegador

JavaScript puede responder a eventos, validar formularios y actualizar una página sin recargarla. La validación del navegador mejora la experiencia, pero los datos también deben validarse en un servidor.
